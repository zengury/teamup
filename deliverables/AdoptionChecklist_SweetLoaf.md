## ⚡ 快速参考：常见问题处理

| 问题 | 怎么办 |
|------|-------|
| **有人说"我不会用"** | 让阿明或小豪教，同龄人教压力小，不要让老板教 |
| **有人说"没时间用"** | 展示"用了反而省时间"——查产品从 3 分钟变 10 秒 |
| **有人说"我用不着"** | 让已经用起来的人分享真实收获 |
| **有人说"老板在监控我吧"** | 陈先生再次承诺："只看整体数据，不用于考核" |
| **有人说"我年纪大学不会"** | 让美珍阿姨做榜样——"美珍 50 岁都会了" |
| **语音识别不准** | 收集具体案例反馈给技术团队，在群里说"已修复" |
| **有人不愿分享经验** | 私下了解原因，承诺"你的名字会挂在 Skill 上" |
