## 一、写在前面：这个计划是做什么的

陈先生您好，我是白龙马，负责帮您把这个 AI 系统真正用起来。

这份计划不是一份"说明书"，而是一张**路线图**。我会告诉您：
- 接下来 3 个月，每一步该做什么
- 怎么让 12 个员工都愿意用、用得顺
- 如果遇到问题，怎么处理
- 最后怎么算清楚这笔投资值不值

> 🎯 **一句话总结**：让 SweetLoaf 的好经验不流失，让新员工上手更快，让您开分店时能直接复制。

## 三、成功指标：怎么知道项目走得好不好

| 指标 | 现在的情况 | 3 个月目标 | 6 个月目标 | 怎么量 |
|------|-----------|-----------|-----------|--------|
| **每人创建了几个 Skill** | 0 个（没人用过） | ≥ 3 个/人 | ≥ 8 个/人 | 系统后台自动统计 |
| **核心岗位有没有 Skill 覆盖** | 0%（全靠人脑记） | 50% | 80% | 店长评估关键工序是否已有 Skill |
| **新员工多久能独立上岗** | 3 个月 | 2 个月 | 1 个月 | 店长记录 |
| **品质投诉率** | 8%（每 100 单有 8 单投诉） | 5% | 3% | 客户投诉记录 |
| **每人每天用几次** | 0 次 | ≥ 3 次/人/天 | ≥ 8 次/人/天 | 系统后台统计 |
| **员工满意度** | 没量过 | ≥ 4.0/5 | ≥ 4.5/5 | 每月匿名问卷 |
| **您看数据的频率** | 不看数据 | 每周看 1 次 | 每天看 1 次 | 后台登录记录 |

> 💡 **给您的话**：这些指标不是用来"考核"员工的，是用来帮您看清楚项目走得好不好。如果某个指标没达到，不是谁做错了，而是我们需要调整方法。

## 四、采用策略：怎么让 12 个人都愿意用

面包店团队不是科技公司，他们不会因为"AI 很酷"就用。**他们用，是因为这东西能帮他们少干活、少犯错、少挨骂。**

### 4.1 按角色定策略

#### 🧑‍🍳 对烘焙师（阿明、小豪等 5 人）— 策略：省力气

| 他们的顾虑 | 我们的对策 |
|-----------|-----------|
| "满手面粉怎么用？" | 全程语音 + 蓝牙耳机，不用碰手机 |
| "我忙得要死，哪有时间搞这个" | 创建 1 个 Skill 只要说几句话，不到 2 分钟 |
| "我为什么要分享我的独门技术？" | 建立荣誉感——Skill 被点赞收藏，有成就感；陈先生承诺：不强制分享，但分享有奖励 |

**具体做法**：
- 阿明带头，先创建 3 个烘焙 Skill，在晨会上展示
- 给 3 位烘焙师配蓝牙耳机（预算约 NT$600/副）
- 告诉烘焙师："这个系统是帮你带徒弟的，不是给你增加工作的"

#### 👩‍💼 对销售（小玲等 4 人）— 策略：省时间

| 他们的顾虑 | 我们的对策 |
|-----------|-----------|
| "客人等着呢，我没空查手机" | 查询只要说一句话，3 秒出答案 |
| "我用得着这个吗？" | 展示"客人问糖尿病面包→马上查到→不用跑后场"的场景 |

**具体做法**：
- 让小玲先创建 2 个"销售话术 Skill"（如"如何推荐新品给常客"）
- 晨会时演示：客人问"这个面包有糖吗？"→ 对着手机问 → 3 秒出答案
- 鼓励销售创建"常见问答 Skill"：把每天被问最多的问题录下来

#### 👩‍🌾 对后勤（美珍等 2 人）— 策略：给模板

| 他们的顾虑 | 我们的对策 |
|-----------|-----------|
| "我不会用手机" | 用模板引导，一步一步来，不用从空白开始 |
| "AI 是年轻人的东西" | 让美珍先试，成功了就是最好的榜样 |
| "我怕按错" | 所有操作都可以用"说的"，不说"系统"，说"对着手机讲话就好" |

**具体做法**：
- 志伟或小玲一对一教美珍，不要催，让她慢慢试
- 用采购模板引导："你这次采购的是什么？怎么判断好坏？"
- 美珍创建第 1 个 Skill 后，在群里公开表扬

#### 👨‍💼 对店长（志伟）— 策略：给工具

| 他的顾虑 | 我们的对策 |
|-----------|-----------|
| "又要多一个系统要管" | 这个系统是帮他省事的——自动出报表、自动排流程 |
| "员工不用怎么办？" | 给他工具（积分赛、龙虎榜）来带动团队 |

**具体做法**：
- 志伟先学会看数据看板，每天 5 分钟看完运营数据
- 志伟负责编排第 1 个自动化流程（"每日开工流程"）
- 志伟负责每周发群消息通报进度

### 4.2 激励方案：让"用"有好处

#### 破冰奖励（第 1 周）

| 奖项 | 奖励 | 评选方式 |
|------|------|---------|
| 前 5 名完成第 1 个 Skill 的人 | 7-11 礼券 NT$200 | 按系统记录时间 |
| 最佳第 1 个 Skill | NT$500 | 陈先生评选 |

#### 积分赛（第 2 周起）

| 行为 | 积分 |
|------|------|
| 创建 1 个 Skill | +10 分 |
| 使用 1 次 Skill（查询/调用） | +2 分 |
| 收藏别人的 Skill | +1 分 |
| 别人收藏了你的 Skill | +5 分 |
| 你的 Skill 被点赞 | +3 分 |

**积分兑换**（您批准）：

| 积分门槛 | 奖励 |
|---------|------|
| 100 分 | 手摇杯一杯（NT$60 以内） |
| 200 分 | 鸡排一份 |
| 500 分 | NT$500 现金红包 |

> 🎯 **关键**：积分兑换要"即时兑现"。今天满 100 分，明天就请喝饮料，这样大家才有动力。

#### 双周评选（第 6 周起）

| 奖项 | 评选标准 | 奖励 |
|------|---------|------|
| 🥇 Skill 之星 | 过去两周创建 Skill 最多的人 | NT$1,000 + 奖状 |
| 🥇 最受欢迎 Skill | 被收藏/点赞最多的 Skill 创建者 | NT$1,000 |
| 🥇 进步最快 | 使用次数增长最多的人 | NT$500 |
| 🎖️ 特别贡献奖 | 您指定的（比如美珍阿姨的采购经验救了大家） | NT$1,000 |

> 💡 **关键**：您要亲自颁奖，哪怕只是在晨会上口头表扬。老板的认可比奖金更有激励效果。

## 五、培训计划：零门槛上手

### 5.1 核心原则

- **不叫"培训"**，叫"一起试试看"——培训这个词会让技术恐惧的人紧张
- **不搞教室**，在后场边做边学
- **每人只要 15 分钟**，超过就是我们的问题

### 5.2 第 1 天：15 分钟启动引导

| 环节 | 时间 | 内容 | 谁来做 |
|------|------|------|-------|
| 扫码加入 | 1 分钟 | 扫二维码打开 LINE Bot / 微信小程序 | 志伟协助 |
| 第 1 次语音记录 | 5 分钟 | "对着手机说一个你今天的工作经验"→ AI 自动整理成 Skill | 员工自己操作 |
| 第 1 次查询 | 3 分钟 | "问系统一个问题"→ 看看 AI 怎么回答 | 员工自己操作 |
| 第 1 次拍照 | 3 分钟 | "拍一张你刚刚做的面包"→ 看看 AI 怎么说 | 员工自己操作 |
| 答疑 | 3 分钟 | 回答疑问，鼓励"试试看" | 志伟/阿明 |

> 🎯 **目标**：每个人在 15 分钟内完成"创建 1 个 Skill + 查询 1 次 + 拍照 1 次"，建立信心。

### 5.3 第 1 周：破冰挑战

**周一晨会（15 分钟）**：
1. （2 分钟）您说三句话：
   > "我搞这个系统，不是为了监控你们，是为了把大家的好经验留下来。"
   > "阿明做了 10 年的酸种，如果哪天他休假了做不了，那是店的损失。我们要把他的经验变成店的资产。"
   > "这个月试用，谁用得好的，月底有奖金。"
2. （5 分钟）阿明展示：他创建 Skill 的过程 + 用时不到 2 分钟
3. （5 分钟）大家一起完成"破冰挑战"：每个人创建自己的第 1 个 Skill
4. （3 分钟）宣布激励机制

**周一到周日**：
- 每个人创建至少 1 个 Skill
- 志伟每天在群里发"今日破冰进度"
- 前 5 名完成的人，周五发 7-11 礼券

**如果有人说"我不知道要创建什么"**：

| 岗位 | 灵感示例 |
|------|---------|
| 烘焙师 | "今天打面的水温怎么调的"、"判断发酵完成的方法" |
| 销售 | "客人问有没有无糖面包时怎么回答"、"推荐新品的话术" |
| 店长 | "每天开店第一件事做什么"、"节假日备货的判断逻辑" |
| 后勤 | "面粉到货怎么检查好坏"、"夏天原料储存注意事项" |
| 学徒 | "我今天学到了什么"（就算只写了一句话也算！） |

> 💡 **第 1 周不追求质量，只追求"有"**。哪怕只写了一句话"今天天气很热，我用了冰水打面"，也算成功。

### 5.4 第 1 个月：习惯养成

| 周数 | 重点 | 具体做法 |
|------|------|---------|
| 第 1 周 | 破冰 | 每人至少 1 个 Skill，全员破零 |
| 第 2 周 | 数量冲刺 | "每日一 Skill"挑战，鼓励每人每天创建 1 个 |
| 第 3 周 | 使用习惯 | 启动积分赛，鼓励多用、多收藏、多点赞 |
| 第 4 周 | 巩固 | 月底统计：人均 Skill ≥ 3 个 |

**可视化进度**：
- 在店里贴一张大海报，画上每个人的"技能树"
- 每创建一个 Skill，就在对应的树枝上贴一个贴纸
- 视觉化进度，大家能看到谁在努力

## 七、风险管理：提前想到的问题和应对

### 7.1 员工不愿意用

| 风险等级 | 🔴 高 |
|---------|-------|
| **可能原因** | 怕学不会、觉得是额外工作、不信任老板、习惯难改 |
| **怎么预防** | ① 您公开承诺"不用于考核" |
| | ② 种子用户带动，先让阿明用起来 |
| | ③ 激励机制到位，让"用"有好处 |
| **如果发生了怎么办** | 如果第 2 周结束仍有 ≥ 3 人未使用： |
| | ① 志伟逐一私下了解原因（不要公开点名） |
| | ② 针对原因调整策略（如"怕学不会"→ 安排一对一教学） |
| | ③ 您再发一次 LINE 群消息，重申"这是帮大家的" |

### 7.2 语音识别不准（闽南语听不懂）

| 风险等级 | 🟡 中 |
|---------|-------|
| **可能原因** | 闽南语识别率不够、后场噪音大、网络延迟 |
| **怎么预防** | ① MVP 阶段重点优化闽南语识别 |
| | ② 后场配蓝牙耳机降噪 |
| | ③ 弱网环境支持离线缓存 |
| **如果发生了怎么办** | 如果出现识别不准导致员工抱怨： |
| | ① 收集具体的识别错误案例（哪句话没识别对） |
| | ② 快速反馈给技术团队优化 |
| | ③ 在群里告知"已修复"，让员工感觉被重视 |

## 八、闽南语使用场景指南

台南团队日常交流以闽南语为主，尤其是后场的烘焙师。这是产品成功的关键——**如果语音识别听不懂闽南语，阿明就不会用**。

### 8.1 常见烘焙闽南语词汇

| 闽南语（罗马字） | 闽南语（汉字拟音） | 意思 |
|----------------|-----------------|------|
| tshn̂g-mī | 搓面 | 打面/揉面 |
| hoat-kàⁿ | 发酵 | 发酵 |
| khòng-ô͘ | 控炉 | 控制烤箱 |
| hong-hé | 风火 | 烤箱的火力 |
| tōa-mī-thôan | 大面团 | 主面团 |
| sió-mī-thôan | 小面团 | 分割后的面团 |
| chhut-lô | 出炉 | 出炉 |
| siuⁿ-chá | 伤早 | 太早了 |
| siuⁿ-âm | 伤暗 | 太深（颜色） |
| siuⁿ-chhìn | 伤浅 | 太浅（颜色） |
| tà-pang | 搭档 | 帮忙/协助 |
| bē-su | 袂输 | 不输/不差 |
| chin hó-chia̍h | 真好食 | 很好吃 |
| ū-iáⁿ | 有影 | 真的吗/真的 |

### 8.2 语音使用建议

| 场景 | 建议 |
|------|------|
| **烘焙师记录经验** | 说闽南语就行，系统自动识别并转成繁体中文显示 |
| **查询产品信息** | 说闽南语或普通话都行，不用切换 |
| **拍照诊断** | 拍照后直接问"这炉有影伤暗？"（这炉是不是太深了？） |
| **系统语音反馈** | MVP 阶段先用普通话或繁体中文文字反馈，后续迭代闽南语语音 |

### 8.3 给年长员工（如美珍阿姨）的引导话术

**不要说**："阿姨，这是 AI 系统，你用语音输入就能创建知识库。"

**要这样说**："美珍姐，你只要对着手机讲台语，它就会帮你记下来。就像跟朋友讲电话一样简单。"

## 十、ROI 测算：这笔投资值不值

### 10.1 可量化的收益

| 收益项 | 怎么算 | 预估月价值 |
|-------|--------|-----------|
| **节省培训时间** | 新员工上手从 3 个月→1 个月，节省 2 个月的人力成本 | 约 NT$60,000/新员工 |
| **减少品质投诉** | 投诉率从 8%→3%，减少 5% 的退款/补偿成本 | 约 NT$8,000/月 |
| **节省店长时间** | 志伟每天少花 1 小时做报表，一个月省 22 小时 | 约 NT$11,000/月 |
| **减少返工成本** | 出错率降低，减少原料浪费 | 约 NT$5,000/月 |
| **经验资产化** | 核心员工经验被保存，降低"人走经验丢"的风险 | 难以量化，但价值巨大 |

**预估每月总收益：约 NT$84,000+**

### 10.2 投入成本

| 成本项 | 预估金额 | 类型 |
|-------|---------|------|
| AI 系统订阅费（月） | 待定（与服务商确认） | 月费 |
| 蓝牙耳机（3 副） | 约 NT$1,800（NT$600/副） | 一次性 |
| WiFi 改善 | 约 NT$3,000（加装 Mesh 路由器） | 一次性 |
| 员工激励（月） | 约 NT$3,000-5,000 | 月费 |

### 10.3 投资回报预估

> **如果每月投入约 NT$10,000-15,000，每月收益约 NT$84,000+，ROI 约 5-8 倍。**

也就是说，**投入 1 块钱，能赚回 5-8 块钱**。而且，随着 Skill 越来越多，收益会越来越大。
